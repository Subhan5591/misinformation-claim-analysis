# Dataset Preparation

This folder contains the scripts and documentation for preparing
the FEVER fact-checking dataset for the AI-Based Misinformation
Context and Claim Analysis System.

## Responsibilities

- Dataset collection
- Dataset inspection
- Data cleaning
- Text preprocessing
- Label mapping
- Dataset preparation for AI/ML model

## Dataset

FEVER (Fact Extraction and VERification)

## Labels

- SUPPORTS → Supported
- REFUTES → Refuted
- NOT ENOUGH INFO → Insufficient Information
