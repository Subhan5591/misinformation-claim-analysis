
# AI-Based Misinformation Context and Claim Analysis System

## About the Project
A web-based AI application that analyses textual claims and helps users understand the reliability of online information using Natural Language Processing (NLP) and fact-checking datasets.

## Problem Statement
The rapid growth of social media and online news platforms has increased the spread of misinformation. This project aims to analyse individual claims, compare them with fact-checking information, and provide evidence-based explanations.

## Key Features
- Text and news claim submission
- NLP-based text preprocessing
- Important claim extraction
- Evidence matching
- Supported, Refuted, or Insufficient Information classification
- Confidence score and explanation
- Analysis dashboard

## Technology Stack
- Frontend: HTML, CSS, Bootstrap
- Backend: Python Flask
- AI: Natural Language Processing
- Similarity: TF-IDF and Cosine Similarity
- Data Processing: Pandas and NumPy
- Database: SQLite

## Datasets
- FEVER Dataset
- LIAR Dataset
